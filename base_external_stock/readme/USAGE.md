To manually use this module, you need to:

1. Go to "Inventory / Configuration / External Inventory Adjustments Configuration"
2. Open your configured inventory adjustment
3. Click on "Create Inventory Adjustment". You will see the created inventory adjustment

Note: If the method configured is the "Asyncronous", the inventory adjustment will be created in progress. The adjustment will be processed with a queue of jobs, that will be called gently by the scheduled action named "External Stock Queues"
